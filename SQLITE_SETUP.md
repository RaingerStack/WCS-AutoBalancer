# SQLite Setup — WarcraftAutoBalance v2.11

Add the provider to the .NET 8 CounterStrikeSharp project:

```bash
dotnet add package Microsoft.Data.Sqlite
```

Build/publish for the actual CS2 host runtime and deploy all required managed and
native SQLite assets generated by NuGet.

The runtime database is:

```text
balance.db
```

WAL mode may also create `balance.db-wal` and `balance.db-shm` while running.

Recommended CS2 convars:

```cfg
mp_autoteambalance 0
mp_limitteams 0
```

For backups, stop/close the database cleanly or use an SQLite-aware backup method
when the server is live.
